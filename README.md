# Hostel-Laundry-Equipment-Borrowing-System

## Project Description

The Hostel Laundry Equipment Borrowing System is a Python-based application designed to manage the borrowing and returning of laundry equipment within a university hostel.

The system allows students to borrow shared laundry equipment such as irons, laundry baskets, and washing buckets while keeping track of equipment availability and borrowing records.

## Features

- Student registration
- Laundry equipment management
- Equipment availability tracking
- Borrowing and returning equipment
- Borrowing record management

## Object-Oriented Programming Concepts

The application demonstrates:

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Method Overriding
- Composition
- Duck Typing

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Run `main.py`.

```bash
python main.py
```
